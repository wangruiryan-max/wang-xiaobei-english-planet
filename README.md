# 王小贝的英语学习星球

这是根据项目中两份历史聊天方案整合完成的小学英语学习软件第一阶段可用版本，不是最终课程库。

## 打开方式

在 Windows 文件资源管理器中双击 index.html，即可在浏览器中使用。

当前包含 8 个主题、40 个基础词汇；每个主题都提供单词认识、听音选择、跟读、应用练习与主题挑战。后续可继续扩展至每个年级的完整课程。

## 文件说明

- index.html：软件入口
- styles.css：界面样式
- fallback.js：当前默认运行的兼容版，提供 8 个主题、40 个词汇、学习、地图、小游戏、语音朗读与成长页
- app.js：保留的增强版学习流程代码，后续用于升级本地记录与更多课程
- 产品方案.md：本版需求与范围
- 聊天记录迁移：原始方案聊天存档

## 隐私

本版本没有账号或服务器。第一阶段会发布为可在微信内直接打开的 HTTPS 网页；后续再视需要制作原生微信小程序。详见 微信发布方案.md。
